# FC Crêperie : site web

Site statique d'une seule page (`index.html`, images incluses dans le fichier).

## Mettre en ligne

1. Créez un dépôt sur github.com (par exemple `fc-creperie`).
2. Sur la page du dépôt : **Add file → Upload files**, puis déposez `index.html`, `vercel.json` et ce README. Validez avec **Commit changes**.
3. Sur vercel.com : **Add New → Project**, puis importez le dépôt GitHub.
   - Framework Preset : **Other**
   - Build Command : vide
   - Output Directory : vide (racine)
4. Cliquez sur **Deploy**. Chaque nouveau commit sur GitHub redéploie automatiquement le site.

## Nom de domaine
Dans Vercel : Project → Settings → Domains, ajoutez par exemple `fccreperie.be`.
